## 2.Technology Description
- Frontend: React@18 + TypeScript + vite
- Backend: None
- Graph/Canvas Layer: 基于 SVG/Canvas 的图编辑渲染（实现缩放、拖拽、选线、删线、布局结果渲染）

## 3.Route definitions
| Route | Purpose |
|---|---|
| /task-input | 任务输入页：模块库选择、模块详情弹窗、已选模块摘要展示 |
| /builder | 图形化搭建页：缩放/拖拽、选线/删线、自动布局与胶水隐藏 |
