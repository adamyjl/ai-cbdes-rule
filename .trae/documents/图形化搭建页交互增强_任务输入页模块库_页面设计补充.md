# 页面设计文档（桌面端优先）

## 全局设计（适用于所有页面）
### Layout
- 桌面端优先：内容最大宽度 1200–1440px（根据你们现有栅格）；画布页可使用全宽。
- 主要布局方式：Flexbox（顶部工具条 + 主内容区），画布区域内部可配合 CSS Grid（左右面板+中心画布）。
- 响应式：
  - ≥1200px：左右面板常驻。
  - 768–1199px：右侧属性面板可折叠为抽屉。
  - <768px：本次不作为重点（保留基础可用）。

### Meta Information
- 通用 Title 规则：`{页面名} - {产品名}`
- 通用 Description：一句话说明页面核心用途（任务输入/图形化搭建）。
- Open Graph：og:title/og:description/og:type=website（沿用你们现有配置即可）。

### Global Styles
- 背景：#0B0F14（深色画布场景）或 #F7F8FA（浅色业务页，按你们现有主题二选一保持一致）。
- 主色（Primary）：用于主按钮与选中态描边。
- 字体：14px 基础字号；标题 16/18/20px 分级。
- 按钮：
  - Primary：实心；hover 提升亮度；disabled 降低不透明度。
  - Secondary：描边；hover 轻微底色。
- 交互态：
  - 选中态：描边 + 发光或高对比色（用于“选线”高亮）。
  - 错误态：红色提示文字 + 控件描边（用于任务输入校验时）。

## 页面 1：任务输入页（模块库选择 + 详情弹窗）

### Layout
- 顶部：页面标题 + 简短说明（可选）。
- 主体：左右双栏（桌面端）。
  - 左侧：模块库列表/选择区。
  - 右侧：已选模块摘要区（含再次查看详情入口）。

### Meta Information
- Title：任务输入 - {产品名}
- Description：选择模块并查看详情，作为后续搭建的输入。

### Page Structure
- Stacked sections + 双栏卡片布局：
  1) Header 区
  2) Content 双栏

### Sections & Components
1) 顶部 Header
- 元素：
  - H1：任务输入
  - 说明文本：提示你需要先选择模块（可选）

2) 左侧：模块库选择区（Module Library Panel）
- 模块库列表
  - 每行/卡片最小信息：模块名称、短摘要。
  - 行级操作：
    - 点击行：打开“模块详情弹窗”。
- 选中态
  - 当前候选模块在列表中高亮（与已选模块概念区分：候选=你刚点的）。

3) 右侧：已选模块摘要区（Selected Module Summary）
- 摘要卡
  - 展示：模块名称、摘要（或关键字段）。
  - 操作：
    - “查看详情”：打开模块详情弹窗（复用同一弹窗）。
    - “更换模块”：回到左侧选择（本质仍是选择行为）。

4) 模块详情弹窗（Module Detail Modal）
- 弹窗结构
  - Header：模块名称 + 关闭按钮（X）
  - Body：
    - 描述（多行）
    - 输入/输出/参数说明（按你们已有字段分组展示；无则不展示）
  - Footer：
    - 主按钮：选择/确认
    - 次按钮：取消
- 交互细则
  - 遮罩层点击：默认关闭（若你们规范允许）
  - ESC：关闭
  - 确认后：更新“已选模块摘要”，并关闭弹窗

## 页面 2：图形化搭建页（缩放/拖拽/选线/删线/布局胶水隐藏）

### Layout
- 典型“编辑器”结构：顶部工具条 + 三栏（左/中/右）。
- 主体三栏（桌面端）：
  - 左侧：可选（若你们已有：节点库/图层；本次不新增强制功能）。
  - 中间：画布（核心）。
  - 右侧：属性/信息面板（用于展示选中连线信息与胶水开关）。

### Meta Information
- Title：图形化搭建 - {产品名}
- Description：通过缩放、拖拽与连线编辑完成图形化编排。

### Page Structure
- Editor layout：
  1) Top Toolbar
  2) Main Workspace（Canvas + Side Panels）

### Sections & Components
1) 顶部工具条（Top Toolbar）
- 左侧：页面名/返回（若你们已有导航则沿用）
- 中部：画布交互工具
  - 缩放比例显示（例如 100%）
  - 缩放 - / + 按钮
  - 复位按钮（回到 100%，并可选居中视图）
- 右侧：编辑动作
  - 自动布局按钮
  - 删除连线按钮（仅当存在“选中连线”时可用）

2) 中间画布区（Canvas Workspace）
- 渲染层（建议分层）
  - 底层：网格/背景（可选，仅用于定位，不属于强制需求）
  - 中层：连线层（Edge Layer）
  - 上层：节点层（Node Layer）
  - 顶层：交互层（Hit Test/Selection Overlay）

- 缩放（Zoom）交互
  - 鼠标滚轮：以鼠标指针为缩放中心（若实现成本高，可退化为画布中心缩放，但需一致）。
  - 工具条按钮：按固定步长缩放（如 10%）。
  - 复位：缩放回 100%，并清晰反馈。

- 拖拽（Pan）交互
  - 命中条件：鼠标按住画布空白区域。
  - 拖拽过程中：光标变为“抓手”态（grab/grabbing）。

3) 连线选中（Edge Selection）
- 点击命中
  - 点击连线：进入选中态，连线高亮（描边加粗/变色）。
  - 点击空白：清除选中。
- 选中反馈
  - 画布高亮
  - 右侧面板显示“已选连线信息”（起点/终点标识）。

4) 删线（Edge Delete）
- 入口
  - 工具条“删除连线”按钮（仅在选中连线时启用）。
  - 键盘：Del/Backspace（仅在焦点不在输入框时生效）。
- 删除后
  - 画布立即移除该连线。
  - 清除选中态。

5) 自动布局（Layout）与胶水隐藏（Glue Visibility）
- 自动布局按钮
  - 点击后：更新节点位置与连线路径（以你们现有布局算法输出为准）。
- 胶水隐藏开关（建议位于右侧面板或工具条）
  - 文案：隐藏布局胶水
  - 行为：仅影响“布局算法产生的胶水/中间占位元素”的可见性，不影响真实节点与业务连线。
  - 默认值：开启（隐藏）。

6) 右侧属性/信息面板（Inspector）
- 模块一：选中连线信息
  - 字段：起点标识、终点标识（或你们内部 ID 的可读化展示）
  - 操作：删除连线（可在此处提供冗余入口，但不强制）
- 模块二：布局设置
  - 开关：隐藏布局胶水
