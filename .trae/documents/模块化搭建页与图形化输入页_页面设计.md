# 页面设计文档：模块化搭建页 & 图形化输入页（桌面优先）

## 0. 全局设计规范（两页通用）

### Layout
- 桌面端优先：12 列栅格 + 三栏工作台布局（左侧资源/节点面板 + 中间画布 + 右侧属性面板）。
- 画布区域使用 Flex 布局自适应撑满；左右侧栏固定宽（可折叠）。
- 响应式：
  - ≥1280px：三栏全开；
  - 768–1279px：右侧属性面板默认折叠为抽屉；
  - <768px：仅保留画布 + 底部工具条（本版本以桌面为主，移动端仅做可用性兜底）。

### Meta Information
- Title：模块搭建工作台 / 图形化输入工作台
- Description：加载分析结果或拖拽搭建流程，自动连线、生成胶水并发布到模块库。
- Open Graph：
  - og:title 同 Title
  - og:description 同 Description
  - og:type website

### Global Styles（Design Tokens）
- 背景：#0B1220（深色工作台）/ 内容卡片：#0F1B2D
- 主色：#3B82F6（按钮/高亮）
- 强调：#22C55E（成功/通过校验）#F59E0B（警告）#EF4444（错误）
- 字体：
  - UI：14px/16px/18px 三档；标题 20–24px
  - 等宽：12–13px（胶水输出/JSON）
- 按钮：
  - Primary：蓝底白字，hover 加深 8%
  - Secondary：描边/半透明底
  - Dangerous：红色系
- 链接：主色 + hover 下划线
- 交互反馈：
  - 节点 hover：外发光描边（主色 30%）
  - 选中：2px 主色描边 + 轻微阴影

### 通用组件
- 顶部工作台栏（Workbench Topbar）：项目名/草稿状态、保存/发布、模块库入口、撤销/重做、帮助。
- Toast：发布成功/保存失败/校验错误。
- Dialog：发布模块、模块详情、导入导出。

## 1. 模块化搭建页（任务分析结果加载）

### 1.1 Page Structure
- 顶部：Workbench Topbar
- 主体：三栏
  - 左栏：分析结果摘要 + 生成规则/自动连线控制
  - 中栏：画布（节点图）
  - 右栏：属性面板（模块字段/校验）
- 底部：状态栏（当前校验状态、节点数/边数、自动保存时间）

### 1.2 Sections & Components

#### A. 顶部工作台栏（Topbar）
- 左侧：页面标题“模块化搭建（分析结果）”、当前草稿名称、保存状态（已保存/保存中/失败可重试）。
- 中间：工具按钮组
  - 撤销/重做
  - 视图：适配画布/1:1/小地图开关
- 右侧：主操作
  - 「模块库」按钮：打开右侧抽屉或弹窗
  - 「发布入模块库」Primary：打开发布对话框

#### B. 左侧栏：任务分析结果区
- 模块 1：结果加载卡片
  - 状态：Skeleton（加载中）/ 错误提示（含重试）/ 成功摘要
  - 成功时显示：识别到的模块数量、关键输入输出摘要
- 模块 2：自动连线控制
  - 开关：自动连线启用/禁用
  - 下拉：连线策略（例如“按输入输出匹配”“按推荐优先级”——仅作为策略选项，不暴露技术实现）
  - 按钮：「重新自动连线」

#### C. 中间：画布区（Node Canvas）
- 画布交互：拖动平移、滚轮缩放、框选多选。
- 节点样式：
  - Header：模块名 + 状态点（通过/警告/错误）
  - Body：关键端口（输入/输出）简要列表
  - Footer：快捷操作（复制、删除、聚焦）
- 连线：
  - 默认曲线；hover 高亮
  - 断开/无效连线显示红色虚线并在右侧面板给出原因

#### D. 右侧：属性面板（Properties）
- 空态：提示“选择一个模块以编辑属性”。
- Tabs：
  1) 基本信息：名称、描述（可选）、标签（可选）
  2) 输入/输出：端口列表、类型/必填标记、映射关系
  3) 校验：错误/警告列表（点击可定位到节点/连线）

#### E. 发布对话框（Publish Dialog）
- 字段：模块名（必填）、描述（必填/或最小长度提示）、标签（可选）、版本说明（必填）。
- 预检：显示将发布的节点数/边数、校验结果（必须“通过”才能发布）。
- CTA：取消 / 发布

#### F. 模块库抽屉（Module Library Drawer）
- 顶部：搜索框 + 标签筛选
- 列表：模块卡片（名称、描述、版本、更新时间）
- 详情区：选中后展示输入输出摘要、版本列表
- 操作：插入到画布 / 复制模块ID

## 2. 图形化输入页（拖拽搭建）

### 2.1 Page Structure
- 顶部：Workbench Topbar（与上一页一致，但标题与主按钮文案变化）
- 主体：三栏
  - 左栏：节点/组件库（可拖拽）
  - 中栏：画布（拖拽 + 连线）
  - 右栏：属性面板（参数/映射/校验）
- 下方：胶水生成区（可折叠面板）

### 2.2 Sections & Components

#### A. 左侧栏：节点库（Palette）
- 分类：常用、控制流、数据处理、外部调用（仅做分类容器，不引入额外功能）。
- 每项：图标 + 名称 + 简述；支持搜索。
- 拖拽：拖到画布后在落点生成节点，并自动打开右侧属性面板。

#### B. 中间画布区（Canvas）
- 辅助：网格背景 + 对齐参考线；吸附开关。
- 连线：从端口拖出连接；不合法连接即时提示（红色 + tooltip）。
- 快捷：
  - Ctrl/Cmd+Z/Y 撤销重做
  - Delete 删除
  - Ctrl/Cmd+C/V 复制粘贴节点

#### C. 右侧属性面板
- Tabs：
  1) 参数：表单化配置（必填标识、默认值）
  2) 映射：输入输出映射（以列表形式管理）
  3) 校验：与上一页一致（定位到节点/边）

#### D. 胶水生成折叠面板（Glue Panel）
- 顶部：面板标题 +「生成胶水」Primary +「复制」+「下载」
- 内容区：
  - 未生成：说明文本 + 生成按钮
  - 已生成：等宽文本区（只读）+ 生成时间
- 交互：仅在你点击“生成胶水”后才生成/更新；若画布已变更，显示“内容已过期”提示并引导重新生成。

#### E. 发布与持久化
- Topbar 中的「发布入模块库」：同上一页对话框结构。
- 自动保存：
  - 保存指示在 Topbar（保存中/已保存/失败）
  - 提供「导入/导出 JSON」入口（放在更多菜单或模块库旁）。
