# 页面设计：代码生成后自动 Diff 回显

## 全局设计规范（适用于本需求涉及页面）
- Layout：桌面优先（Desktop-first）。主容器最大宽度 1200–1440px（按现有系统风格对齐）；内容区以 Flexbox 为主。
- Meta Information：
  - 代码生成页面：Title「代码生成」；Description「生成代码并查看差异回显」。
  - Diff 回显页面：Title「Diff 回显」；Description「左右对比旧代码与新代码差异」。
- Global Styles（与现有系统一致，以下为建议 token，用于描述交互状态）：
  - 背景：#0B0F14 或系统既有背景色；卡片/面板：#111827
  - 文本：主文本 #E5E7EB；次文本 #9CA3AF
  - Diff 标识：新增（绿）#16A34A 的浅背景；删除（红）#DC2626 的浅背景；中性高亮（修改）可沿用新增/删除组合效果
  - 行号区域：固定窄列（48–64px），弱化颜色 #6B7280
  - Hover：按钮/菜单项 hover 提升背景对比度与边框

---

## 页面 1：代码生成页面
### Layout
- 页面主体为纵向堆叠：顶部（标题/菜单）+ 中部（生成输入/操作）+ 底部（结果区域，沿用现有）。
- 使用 Flexbox：主列垂直排列；按钮区右对齐。

### Page Structure
1. 顶部栏/菜单栏（现有）
2. 生成操作区（现有）
3. 结果区（现有）

### Sections & Components（仅描述本次新增/调整点）
- 菜单项：在菜单栏新增「调测工具」下的子项「diff」
  - 点击行为：打开 Diff 回显页面（同一窗口路由跳转或以子页面形式打开，遵循现有产品的“子页面/弹出”模式）。
- 自动打开 Diff：
  - 触发时机：代码生成成功回调后立即触发。
  - 打开方式：弹出/子页面打开 Diff 回显页面。
  - 数据准备：把“旧代码/新代码”对比所需数据写入 Diff 回显模块可读取的位置（例如内存状态 + 可选 LocalStorage 作为再次打开的来源）。

## 页面 2：Diff 回显页面（子页面）
### Layout
- 桌面端两栏对比：CSS Grid（推荐）或 Flexbox。
  - Grid：`grid-template-columns: 1fr 1fr`，列间距 12–16px。
  - 每列内部：行号列 + 代码内容列（可用子 Grid/Flex 实现）。
- 顶部固定工具条：包含页面标题与关闭/返回入口（如产品已有关闭方式则沿用）。

### Page Structure
1. 顶部工具条
2. 双栏 Diff 主体（左旧/右新）
3. 空状态（无可用 Diff 时）

### Sections & Components
1) 顶部工具条（Header）
- 左侧：标题「Diff 回显」
- 右侧：关闭/返回（返回到代码生成页面或关闭子页面，取决于现有“弹出”实现）

2) Diff 主体（Main）
- 左侧面板：旧代码
  - 行号：独立列展示，从 1 开始
  - 变更高亮：对“删除/被替换”的行使用红色标识
- 右侧面板：新代码
  - 行号：独立列展示，从 1 开始
  - 变更高亮：对“新增/替换后”的行使用绿色标识
- 代码区域：等宽字体（如 ui-monospace / SFMono-Regular / Menlo），保留原始缩进与换行。

3) 变更标识规则（视觉层）
- 新增行：绿色浅底 + 左侧细条（绿）
- 删除行：红色浅底 + 左侧细条（红）
- 未变更行：普通背景

4) 空状态（Empty State）
- 文案：提示“当前没有可回显的 Diff，请先完成一次代码生成”。
- 行为：提供返回入口到代码生成页面（或引导用户使用生成入口）。
