# 投屏友好浅色主题与任务TAB顶部化（页面设计补充）

## Global Styles（全局样式与设计 Token）
- 设计目标：远距离观看清晰、低视觉噪音、交互区域更大更明确。
- 主题：浅色主题（投屏友好）
- 颜色（按指定值）：
  - 主色（页面大面积背景）：#FFFFFF
  - TAB 边框：rgb(95, 2, 107)
  - 画布背景：rgb(252, 248, 242)
  - 函数块背景：rgb(227, 212, 229)
- 字体与可读性（投屏友好建议）：
  - 基础字号：16px 起；关键标题/当前任务名 18–20px
  - 行高：1.4–1.6
  - 默认文字颜色：深灰（避免纯黑刺眼），但需保证对比度
- 按钮与交互态：
  - Hover：背景轻微加深/描边加粗（二选一即可），避免仅靠细微颜色变化
  - Focus：明显外描边（2px）或阴影环，便于演示时键盘操作
- 分割与层次：
  - 以“边框 + 间距”为主，阴影尽量克制（投屏时阴影易脏）

## Page 1：模块化搭建页（/task-builder）

### Layout
- 桌面优先：顶部固定区 + 主内容区（左右/中间分栏）混合布局。
- 推荐：整体使用 Flexbox：
  - 外层 column：TopBar（固定） + Main（flex:1）
  - Main 内 row：左侧模块区（如现有） + 中央画布 + 右侧属性/配置区（如现有）

### Meta Information
- Title：模块化搭建
- Description：在投屏友好浅色主题下进行任务搭建与演示。
- Open Graph：
  - og:title = 模块化搭建
  - og:description = 投屏友好浅色主题 + 顶部任务 TAB

### Page Structure
1. TopBar（顶部区，固定）
2. Main（主内容区）
   - Left Panel（如现有：模块库/组件库/资源区）
   - Canvas（画布区）
   - Right Panel（如现有：属性面板/配置面板）

### Sections & Components
#### 1) TopBar
- 结构：
  - 左侧：页面标题/返回（如现有）
  - 中间：任务 TAB 条（本次从左侧迁移到顶部）
  - 右侧：全局操作（如现有）
- 任务 TAB 样式：
  - TAB 容器背景：#FFFFFF
  - TAB 边框：rgb(95, 2, 107)
  - 选中态：边框更粗或底部下划线（同色 rgb(95,2,107)）
  - 点击热区：高度不低于 36–40px，便于投屏时准确点击

#### 2) Canvas（画布）
- 背景色：rgb(252, 248, 242)
- 画布内辅助元素（如网格/参考线）：使用更淡的线条，避免抢眼。

#### 3) 函数块（节点）
- 背景色：rgb(227, 212, 229)
- 建议：
  - 标题区字号更大（>=16px），关键信息优先
  - 选中态提供明显外描边/阴影环（投屏可见）

## Page 2：图形化输入页（/visual-builder）

### Layout
- 桌面优先：同模块化搭建页，保持“顶部任务 TAB + 中央画布”的一致心智。
- 推荐：TopBar 固定 + Main 分栏（按现有信息架构保留）。

### Meta Information
- Title：图形化输入
- Description：以投屏友好浅色主题进行图形化搭建与任务切换。
- Open Graph：
  - og:title = 图形化输入
  - og:description = 顶部任务 TAB + 浅色画布

### Page Structure
1. TopBar（顶部区，固定：含任务 TAB）
2. Main（主内容区：画布为核心，周边面板按现有保留）

### Sections & Components
#### 1) TopBar / 任务 TAB
- 与 /task-builder 复用同一组件与样式 Token（保证一致性）。
- TAB 边框色：rgb(95, 2, 107)

#### 2) Canvas / 节点
- 画布背景：rgb(252, 248, 242)
- 函数块背景：rgb(227, 212, 229)
- 投屏可读性要求：
  - 连接线/端口在浅色背景下可清晰识别（必要时加粗）
  - 文本与图标避免过细线条
