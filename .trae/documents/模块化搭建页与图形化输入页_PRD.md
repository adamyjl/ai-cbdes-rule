## 1. Product Overview
面向“任务/流程搭建”的两种编辑体验：结果驱动的模块化搭建与拖拽驱动的图形化输入。  
帮助你将分析结果或手工搭建的流程沉淀为可复用模块，并支持自动连线、持久化与发布入模块库。

## 2. Core Features

### 2.1 Feature Module
本产品需求包含以下核心页面：
1. **模块化搭建页（任务分析结果加载）**：结果加载、模块生成、自动连线、编辑与校验、发布入模块库、草稿/版本持久化。
2. **图形化输入页（拖拽搭建）**：拖拽搭建、连线与编排、可选生成胶水、发布入模块库、草稿/版本持久化。

## 3. Core Process
### 模块化搭建页（任务分析结果加载）主流程
1) 进入页面后加载任务分析结果并生成初始节点图。  
2) 系统进行自动连线与基础校验；你在画布上手工修正连线与模块参数。  
3) 通过校验后，你选择“发布入模块库”，填写模块信息并发布版本。  
4) 系统持续自动保存草稿；你可随时恢复到某个保存点。

### 图形化输入页（拖拽搭建）主流程
1) 你从节点面板拖拽节点到画布并连线形成流程。  
2) 在属性面板配置参数与映射，解决校验提示。  
3) （可选）点击“生成胶水”，得到可复制/下载的胶水内容。  
4) 你选择“发布入模块库”形成可复用模块；系统自动保存草稿与版本。
