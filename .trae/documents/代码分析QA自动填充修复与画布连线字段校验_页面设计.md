# 页面设计：代码分析 QA 自动填充修复与画布连线字段校验

## Global Styles（全局样式规范，桌面优先）
- 画布背景：#0F1115（深色）或沿用现有主题；网格线低对比（透明度 6%）。
- 主要文字：#E6E8EB；次级文字：#A9AFB7；危险/阻止：#FF4D4F；提示：#FAAD14；成功：#52C41A。
- 字体：
  - 基础字号 14px；标题 16/18px；代码编辑器等宽字体 12/13px。
- 按钮：
  - Primary：实底（主题色），hover 提亮 6%，disabled 降低透明度。
  - Danger：红色边框/实底用于“阻止连线”等。
- 交互反馈：
  - Toast：用于生成失败、校验阻止原因简述。
  - Inline Banner：用于 QA 面板“本次未生成 QA / 使用上次成功版本”。

## Page 1：工作台（画布+代码分析+QA）

### 1) Layout
- 桌面优先三栏结构（CSS Grid）：
  - 左侧：画布区（自适应，占 1fr）
  - 右侧：属性面板（固定 360–420px，可折叠）
  - 底部：QA 面板（高度 280–360px，可拖拽调整/折叠）
- 画布区内部：顶部工具条 + 主画布视口（100% 高宽，支持缩放/平移）。

### 2) Meta Information
- Title：工作台 - 图形化搭建
- Description：在画布上连接模块、生成分析与 QA，并通过胶水函数解决字段不匹配。
- Open Graph：沿用站点默认（如有）。

### 3) Page Structure
1. 顶部工具条（全宽）
2. 主区域：画布视口 + 右侧属性面板
3. 底部：QA 面板（与画布同页，避免跳转）
4. 全局浮层：
   - 字段不匹配弹窗（胶水函数生成）
   - Toast/Confirm

---

### 4) Sections & Components

#### A. 顶部工具条（Toolbar）
- 左侧：项目/任务标题（可省略编辑），生成状态点（running/success/failed）。
- 中间：画布工具（选择/连线/缩放 100%/适配视图/撤销重做）。
- 右侧：
  - 主按钮「代码分析/生成」
  - 次按钮「重试」仅在 failed 显示
  - 生成运行信息：RunId 简写 + 时间

交互细节：
- 点击「代码分析/生成」后：按钮进入 loading，旁边显示“生成中…”。
- 多次点击：若已有 running，提示“已有生成任务进行中”。

#### B. 画布视口（Canvas Viewport）
- 节点卡片：
  - 顶部：节点名称 + 类型标签（例如 Function/Module/Glue）
  - 左侧端口：输入 ports
  - 右侧端口：输出 ports
- 连线交互（新增校验反馈）：
  - 拖拽过程中：连线为预览状态（虚线）。
  - 松开时触发校验：
    - Pass：线条变为实线，颜色=主题色
    - Mappable：不立即落线，弹出胶水函数弹窗
    - Block：预览线消失，端口抖动一次（可选），Toast 显示阻止原因

端口提示（hover）：
- 显示端口字段概览（前 5 个字段）+ “查看全部”。

#### C. 右侧属性面板（Properties Panel）
- Tabs：节点属性 / 端口 Schema / 运行信息
- 当选中 Glue 节点：
  - 映射表（from → to，支持新增/删除行）
  - 代码区域（只读预览 + “编辑”按钮或直接可编辑，依据你现有交互习惯）
  - 操作：复制代码、重建映射（打开弹窗）

#### D. 底部 QA 面板（QA Panel）
目标：修复“生成后为空”并让状态可感知。

组件结构：
- Header：
  - 标题「建议 Q/A」
  - 右侧状态：
    - success：显示“已更新（RunId…）”
    - running：显示“生成中，完成后自动填充”
    - failed：显示“生成失败”+「重试」
- 内容区：
  - 列表卡片：Question（可折叠）+ Answer
  - 空态（仅在从未成功过时）：引导点击「代码分析/生成」
- Banner（关键）：
  - 若本次生成结果缺少 QA：显示“本次未生成 QA，已保留上次结果”+ 详情按钮

交互与容错：
- 若你切换选中节点/切换右侧 tab，不影响 QA 面板内容。
- 若你快速重复触发生成：只展示最新 Run 的结果；旧 Run 完成后不应覆盖。

## 弹窗：字段不匹配（胶水函数生成）

### Layout
- 桌面居中 Modal，宽 920px，高度自适应（最大 80vh），内部左右分栏 + 底部代码区。
- Header：标题「字段不匹配：生成胶水函数」+ 简要原因。

### 内容结构
1) 差异摘要（顶部小面板）
- 左：源端口信息（节点名/端口名）
- 右：目标端口信息
- 中：差异结论（缺失字段数、类型不一致数）

2) 字段映射编辑区（主分栏）
- 左表：源字段（支持搜索）
- 右表：目标字段（required 高亮）
- 中间：映射连线/选择器（最小可用：表格行 from/to 下拉）
- 自动推荐：默认预填 suggestedMappings；你可手动调整。

3) 代码生成区（底部）
- 代码编辑器：默认生成的胶水函数（TypeScript/JS 语法高亮）
- 说明：输入/输出类型（由 schema 推导）

### Footer Actions
- Secondary：「取消」不做任何变更
- Primary：「生成并注入画布」创建 Glue 节点并自动重连

### Interaction States
- Primary disabled：当 required 目标字段仍未被映射时禁用，并在缺失行标红。
- 生成中：按钮 loading；完成后自动关闭弹窗，并在画布聚焦新插入的 Glue 节点（可选）。
